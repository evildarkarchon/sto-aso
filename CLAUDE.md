## Agent skills

### Issue tracker

Issues and specs live in local Markdown under `.scratch/<feature>/`. Read `docs/agents/issue-tracker.md` before creating, reading, updating, or closing tickets.

### Triage labels

Use the five default triage roles. Read `docs/agents/triage-labels.md` when assigning triage status.

### Domain docs

Single-context layout: root `CONTEXT.md` and `docs/adr/`. Read `docs/agents/domain.md` before exploring domain concepts or proposing architecture changes.
